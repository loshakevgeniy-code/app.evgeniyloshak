# app.evgeniyloshak

Личный кабинет Евгения Лошака и первый продукт — электронная карточная игра «Кажется, я тебя знаю».

## Что уже реализовано

- вход по email и паролю с защищённой долгоживущей сессией;
- каталог продуктов и отдельное право доступа к игре;
- расширенная колода из 70 карточек;
- партии на 4 и 8 вопросов, выбор из пары, догадки, пропуски и исчерпание главы;
- уточняющие и специальные карточки без изменения прогресса;
- пауза, добровольный финал и экспорт обсуждённых вопросов;
- локальное сохранение партии, настроек и избранного без сохранения ответов;
- защита от повторных команд и конфликта двух вкладок;
- крупный текст, reduced motion и адаптивная вёрстка;
- PWA-манифест и service worker: кабинет устанавливается на домашний экран, но проверка доступа требует сети;
- серверная выдача колоды только пользователям с активным правом доступа.

## Локальный запуск

Нужен Node.js 24+.

```bash
npm install
NODE_ENV=development PORT=8788 \
  DATABASE_PATH=./data/cabinet.sqlite \
  APP_ORIGIN=http://127.0.0.1:5173 \
  BOOTSTRAP_ADMIN_EMAIL=test@example.com \
  BOOTSTRAP_ADMIN_PASSWORD='replace-with-a-long-password' \
  BOOTSTRAP_ADMIN_NAME='Тест' \
  npm run dev:server
```

Во втором терминале:

```bash
npm run dev
```

Сборка и проверки:

```bash
npm test
npm run build
```

## Доступ пользователей

Продакшен-пароль хранится только в `/srv/app.evgeniyloshak/.env` на сервере. Добавить или обновить тестового пользователя можно внутри контейнера:

```bash
docker compose exec app node scripts/manage-user.mjs \
  --database /data/cabinet.sqlite \
  --email user@example.com \
  --password 'a-long-random-password' \
  --name 'Имя'
```

Опциональный срок доступа задаётся в ISO-формате через `--valid-until`. Таблицы `products` и `entitlements` готовы к подключению платёжного webhook позднее.

## Развёртывание

Приложение работает одним контейнером и подключается к общей сети Caddy существующего сервера. В Caddy добавляется отдельный хост:

```caddy
app.evgeniyloshak.ru {
  encode gzip zstd
  reverse_proxy app-evgeniyloshak:3000
}
```

DNS-запись у регистратора:

```text
Тип: A
Имя: app
Значение: 212.69.85.62
TTL: 300 или Auto
```

Основной сайт и его DNS-записи не изменяются.

## Приватность и коммерческий доступ

Ответы пользователей не вводятся в приложение и не уходят на сервер. Сервер хранит аккаунт, хэш пароля, сессию и право на продукт. Колода выдаётся после проверки доступа и не кэшируется service worker. Как и у любого цифрового продукта, авторизованный пользователь технически может сохранить увиденный контент; это контроль доступа, а не DRM.

Полное исходное ТЗ и визуальный референс сохранены в каталоге `docs/`.
